# JJ象棋绝杀特效原生前端版

不需要 React、Vite、npm 或 Node.js。

## 文件

- `index.html`
- `styles.css`
- `app.js`
- `video.mp4`（请自行放入，当前压缩包未重复包含22MB视频）

## 本地运行

不要直接双击 HTML，建议在目录中启动静态服务器：

```bash
python3 -m http.server 8080
```

然后打开 `http://localhost:8080`。

## GitHub Pages

将这几个文件放在仓库根目录，并让视频命名为 `video.mp4`。随后进入仓库 `Settings > Pages`，选择 `Deploy from a branch`、`main`、`/(root)`。
